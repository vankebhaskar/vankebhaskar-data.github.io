Banking Transaction Performance Dashboard

Power BI Practice Project | Branch Performance · Transaction Trends · KPI Analysis

Project Overview

This project demonstrates banking MIS reporting and business intelligence skills through an interactive Power BI dashboard. It analyzes transaction performance, branch activity, customer trends and key performance indicators using sample data.

Tools and Technologies

Power BI DAX Power Query Excel Data Modeling

Dashboard Features

  • Total Transaction Value KPI
  • Month-over-Month Growth Analysis
  • Year-to-Date Transaction Value
  • Total Customers KPI
  • Monthly Transaction Trends
  • Branch-wise Transaction Performance
  • Transaction Type and Status Analysis
  • Top 10 Branches by Transaction Value
  • Interactive Year, Branch and Transaction Type slicers

Key Skills Demonstrated

  • Building data models and table relationships
  • Creating DAX measures for business KPIs
  • Analyzing monthly and year-to-date performance
  • Designing interactive MIS dashboards
  • Validating measures and testing slicer interactions
